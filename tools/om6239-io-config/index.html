    怎么接进工程
      
        
    1. io_config.h、io_config.c 存到 projects/mouse_demo/periph/，io_board.h 存到 projects/mouse_demo/config/，覆盖原文件（UTF-8 编码）。
      2. 
        
    2. io_board.h 是编码器等外设的开关，board_config.h 会自动包含它，不用改别的代码。
      3. 
        
    3. main.c 加 #include "io_config.h"，用 io_config_init(); 替换 main() 开头直接写 PAD_PU_CTRL 到 OUTENCLR 的那几行。
      4. 
        
    4. 唤醒脚：在 mouse_periph_wakeup_enable() 里，用 io_config_wakeup(true / false) 替换逐个设置唤醒脚的代码。
      5. 
        
    5. 生成的宏都带 IO_ 前缀，和 main.h 里的旧宏不冲突，可以逐步替换。
      6. 
      
    
      
    生成规则
      
        
    1. 上下拉、驱动、输入缓冲、唤醒都按整寄存器写，每行后面注明涉及哪些脚。
      2. 
        
    2. 先写 DATAOUT 再开输出，上电不会出毛刺。非输出脚的 DATAOUT 位写 1。
      3. 
        
    3. 上拉编码按手册 V0.1：01 = 30k，10 = 150k。
      4.
